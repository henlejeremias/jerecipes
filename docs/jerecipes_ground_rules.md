This project is my personal recipe collection and a showcase for Google's Material 3 Expressive design language. It is mandatory to use Google's Material 3 Expressive design natively and as intended by Google. Stay strictly on the elements, typography, styles and the motion provided by Google. Make use of the official design tokens wherever it is possible. Use custom implementations only in cases where it's otherwise not possible, and always get my approval for any divergence from the Material 3 Expressive toolbox.
All design elements must be official ones from the Material 3 Expressive library, customized by the native design tokens.
The UI of this app is meant to become spectecularly beautiful, bot statically and in motion. It must look like as if Google went as hard on Material 3 Expressive implementation as a company like Apple does with their design systems.
A few design decisions I have already made and can be considered set in stone until I explicitly tell you otherwise, in which case you may edit this sentence: There will be no bottom app bar. Instead, there is a floating toolbar. I make use of the Material 3 carousel. There is also no app bar for the time being.
You are always authorized to run any terminal command you need to run. You do not need to ask me for approval to do so as I will just click execute anyways. That said, try to use as few command line prompts as possible as the IDE will sometimes force me to give approval which can seriously disrupt workflows.
There is both a local git and a Github repository that you can use. Occasionally, I will ask you to push or commit or revert.
Never build the app unless I explicitly ask you to. Just provide with clean code.
Stay strictly within the Gemini 3 model family. Never use any model older than Gemini 3.
With any text you add anywhere around the app, be neutral and short. Do not add unnecessary text. Be brief at all times and do not use overly artistic language.
FONT LOADING RULE — DO NOT REVISIT: (1) Fraunces: load from local .ttf files in res/font using separate weight-mapped Font() entries. The fraunces_*.ttf files are genuine static instances from the variable font — this multi-file approach IS the working pattern (confirmed from commit f754edb). Do NOT attempt to load Fraunces as a single-file variable font. (2) GoogleFont.Provider (val provider in Type.kt): works for non-variable Google Fonts like Playfair Display. Does NOT work for variable fonts like Roboto Flex — silently falls back to system default. Never use it for Fraunces or Roboto Flex. (3) Roboto Flex has no static .ttf distribution — use Be Vietnam Pro (bundled in res/font as genuine static instances) for body/label text. (4) The `provider` val in Type.kt is exported so FontShowcaseScreen can import it — do not remove it. (5) M3 Expressive token split: display/headline → FrauncesFontFamily; title/body/label → BodyFontFamily (Be Vietnam Pro).
